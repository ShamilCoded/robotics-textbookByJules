# Module 1: The Robotic Nervous System (ROS 2)

**Focus:** Middleware for robot control.

In this module, we focus on the foundational middleware that powers modern robotics.

*   **ROS 2 Nodes, Topics, and Services**: Understanding the communication graph.
*   **Bridging Python Agents to ROS controllers using rclpy**: Writing code to control the robot.
*   **Understanding URDF (Unified Robot Description Format) for humanoids**: Modeling the robot's physical structure.
